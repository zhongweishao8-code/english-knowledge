## 💡 学习技巧

### 语法学习技巧
1. **理解规则**: 不要死记硬背，要理解为什么
2. **学习例句**: 通过例句理解用法
3. **做练习题**: 通过做题巩固知识
4. **总结规律**: 找出规律，形成记忆

### 阅读理解技巧
1. **快速阅读**: 第一遍快速了解大意
2. **逐句阅读**: 第二遍逐句理解细节
3. **查找关键信息**: 第三遍查找答题所需信息
4. **做题技巧**: 
   - 先读题目，再读文章
   - 在文章中标记关键信息
   - 用排除法选择答案

### 错题分析技巧
1. **记录错题**: 建立错题本
2. **分析原因**: 为什么做错了？
3. **学习正确答案**: 理解正确答案的原因
4. **举一反三**: 找出类似的题目，加强练习
