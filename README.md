## 🔍 如何使用

### 1. 按单元学习
按照学校的教学进度，逐个单元学习：
1. 学习单词表
2. 阅读语法讲解
3. 完成练习题
4. 复习巩固

### 2. 专题突破
针对自己的薄弱环节进行专题学习：
- 语法专题
- 词汇专题

### 3. 考前复习
使用复习资料进行系统复习：
- 综合练习题库
- 学习计划和复习指南

## 💡 学习建议

### 每日学习流程
```
早晨：复习昨天的单词 (10分钟)
午后：学习新单元内容 (30分钟)
傍晚：做练习题 (20分钟)
睡前：预习明天内容 (10分钟)
```

### 定期复习
- 📅 每天：复习当天学习的单词
- 📅 每周：复习本周学习的语法点
- 📅 每月：做一套综合测试题
