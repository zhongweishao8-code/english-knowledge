## 词根词缀概览

词根词缀是英语词汇的重要组成部分。通过学习常见的词根和词缀，可以快速扩大词汇量，并能推断出陌生词汇的含义。

### 词根、词缀、词干的关系

| 概念 | 定义 | 例子 |
|------|------|------|
| **词根** | 词汇的核心部分，承载主要含义 | music, communicate, protect |
| **词缀** | 添加到词根前后的部分，改变词义或词性 | un-, re-, -tion, -ment |
| **词干** | 词根加上词缀后的形式 | communicate + tion = communication |

| 前缀 | 原词 | 新词 | 中文 |
|------|------|------|------|

| un- | safe | unsafe | 不安全的 |
| un- | kind | unkind | 不友好的 |
| un- | lucky | unlucky | 不幸运的 |

**七年级下册例子**:
- Unit 1: unknown (不出名的)
- Unit 4: unhappy (不高兴的)

- honest → **unhonest** (不诚实的)
- comfortable → **uncomfortable** (不舒适的)

## 常见后缀 (Suffixes)

### 1. -tion/-sion (名词后缀，表示动作或状态)

| 后缀 | 动词 | 名词 | 中文 |
|------|------|------|------|
| -tion | communicate | communication | 交流 |
| -tion | protect | protection | 保护 |
| -tion | create | creation | 创造 |
| -tion | describe | description | 描述 |
| -sion | decide | decision | 决定 |

**七年级下册例子**:
- Unit 1: communication (交流)
- Unit 3: protection (保护)
- Unit 5: creation (创造)

**规则**:
- 动词以 -ate 结尾，去 -ate 加 -tion：communicate → communication
- 动词以 -de 结尾，去 -de 加 -sion：decide → decision

**练习**:
- educate → **education** (教育)
- celebrate → **celebration** (庆祝)
- divide → **division** (分割)

## 词根词缀综合练习

### 练习 1：识别前缀和后缀

1. **un**happy - 前缀 un- 表示否定
2. **re**build - 前缀 re- 表示重新
3. communi**cation** - 后缀 -tion 表示动作
4. kind**ness** - 后缀 -ness 表示性质
5. beauti**ful** - 后缀 -ful 表示充满
6. care**less** - 后缀 -less 表示没有
7. quick**ly** - 后缀 -ly 表示方式
8. teach**er** - 后缀 -er 表示人

### 练习 2：根据词根推断词义

1. **un**known - 不出名的 (known = 出名的)
2. **re**write - 重写 (write = 写)
3. **dis**like - 不喜欢 (like = 喜欢)
4. **mis**understand - 误解 (understand = 理解)
5. **im**possible - 不可能的 (possible = 可能的)

### 练习 3：根据词根构造新词

1. honest + -ly = **honestly** (诚实地)
2. happy + -ness = **happiness** (幸福)
3. care + -ful = **careful** (小心的)
4. help + -less = **helpless** (无助的)
5. communicate + -tion = **communication** (交流)
6. encourage + -ment = **encouragement** (鼓励)
7. beautiful + -ly = **beautifully** (美妙地)
8. teach + -er = **teacher** (教师)

### 练习 4：填空题

1. The **________** (communicate) between them was good.
   **答案**: communication

2. She is a very **________** (care) person.
   **答案**: careful

3. He spoke **________** (beautiful) at the concert.
   **答案**: beautifully

4. The **________** (popular) of this song is increasing.
   **答案**: popularity

5. We should **________** (encourage) each other.
   **答案**: encourage

6. This is an **________** (possible) task.
   **答案**: impossible

7. The **________** (kind) of the teacher helped me a lot.
   **答案**: kindness

8. She is a very **________** (create) person.
   **答案**: creative

### 练习 5：改写句子

1. I like music. → I **dislike** music. (加前缀 dis-)
2. The song is known. → The song is **unknown**. (加前缀 un-)
3. He wrote the book. → He **rewrote** the book. (加前缀 re-)
4. She understood the meaning. → She **misunderstood** the meaning. (加前缀 mis-)
5. The task is possible. → The task is **impossible**. (加前缀 im-)

## 总结

### 关键要点
1. **前缀** - 改变词义，通常表示否定、重新、错误等
2. **后缀** - 改变词性，通常表示名词、形容词、副词等
3. **词根** - 词汇的核心，承载主要含义
4. **组合** - 前缀 + 词根 + 后缀 = 新词

### 学习建议
- 每天学习 2-3 个词根词缀
- 做练习题巩固
- 在阅读中识别词根词缀
- 在写作中应用词根词缀
- 定期复习和总结
