## 📊 词汇学习技巧

### 词根词缀记忆法
```
前缀 + 词根 + 后缀 = 新词汇

例如：
un- + known = unknown (前缀表示否定)
beauty + -ful = beautiful (后缀表示形容词)
```

### 同义词联想记忆
```
like ≈ enjoy ≈ love (喜欢程度的递进)

例如：
I like music. (我喜欢音乐)
I enjoy listening to music. (我喜欢听音乐)
I love classical music. (我热爱古典音乐)
```

### 反义词对比记忆
```
like ↔ dislike (喜欢 ↔ 不喜欢)
beautiful ↔ ugly (美丽 ↔ 丑陋)
```
