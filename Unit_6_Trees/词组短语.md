## 句型

| 句型 | 中文 | 例句 |
|------|------|------|
| What is special about...? | ...有什么特别的？ | What is special about this tree? |
| It has... | 它有... | It has thick branches. |
| It provides... | 它提供... | It provides good shade. |
| Why are...important? | ...为什么重要？ | Why are trees important? |
| Trees provide... | 树提供... | Trees provide oxygen. |
| Trees help... | 树帮助... | Trees help prevent erosion. |
| Trees are essential for... | 树对...至关重要。 | Trees are essential for survival. |
| In many cultures... | 在许多文化中... | In many cultures, trees hold significance. |
| Some...are considered... | 有些...被认为是... | Some trees are considered sacred. |
| Others are symbols of... | 其他的是...的象征。 | Others are symbols of strength. |
| Today, ...are disappearing... | 今天，...正在消失... | Today, forests are disappearing. |
| We must... | 我们必须... | We must protect our trees. |
| By...we can... | 通过...我们可以... | By planting trees, we can help. |
| We can support... | 我们可以支持... | We can support conservation efforts. |
| We can use... | 我们可以使用... | We can use sustainable products. |
| We can reduce... | 我们可以减少... | We can reduce paper consumption. |
| We can educate... | 我们可以教育... | We can educate others. |
| By working together... | 通过一起工作... | By working together, we can ensure. |
| ...are symbols of... | ...是...的象征。 | Cherry blossoms are symbols of spring. |
| They bloom for... | 它们开花... | They bloom for a short time. |
| ...are the tallest... | ...是最高的... | Redwoods are the tallest trees. |
| Some are over... | 有些超过... | Some are over 2,000 years old. |
| ...can live for... | ...可以活... | Baobab trees can live for thousands of years. |
| They store... | 它们储存... | They store water in trunks. |
| ...are ancient trees. | ...是古老的树。 | Ginkgo trees are ancient trees. |
| They are symbols of... | 它们是...的象征。 | They are symbols of longevity. |
